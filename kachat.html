Chat

Connect a wallet, or skip.

Connect Kasware or Kastle, pick the domain you want as your name, then continue. Or skip and create a wallet inside KaChat. This site never asks for a recovery phrase.

What KaChat is

Peer-to-peer messages on the blockDAG. No phone number. No central account. This page asks how you want to enter. The desktop client is one step further, at /kachat/app. Android is an APK. iOS is a separate repo.

Desktop

STP source: STP-KAS/kaachat-desktop ↗. Upstream: KaspaSilver/KaChat-Desktop ↗. To run it yourself:

git clone https://github.com/STP-KAS/kaachat-desktop.git
cd kaachat-desktop
npm install
npm run dev

Then open the address Vite prints (usually http://localhost:5173/).

Phone

Android APK: KaChat 4.1 release ↗ (KaChat-4.1-vc39.apk ↗). Install from that source if Android asks. iOS: vsmirn0v/KaChat ↗. Kastle injects in a mobile browser. Kasware does not.

Wallets

You choose. On a computer, Kasware and Kastle link inside the Chat client in this tab. KasVault/Ledger, Kaspium, Kaspa NG, Tangem, OneKey, KasKeeper, Kurncy, and Zelcore stay in their own app. Never paste a seed on this site.

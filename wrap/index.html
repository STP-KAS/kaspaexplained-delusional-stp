    What this proves

    Native receipt. Test KAS is held in the covenant output. Transfer changes who owns the claim. Redemption consumes it and releases the backing. Only a node-reported accepting block counts as accepted here.

    External bridge. The source vault holds the test asset. A trusted oracle authorizes issuance on Kaspa and source release after a burn. Source receipts and Kaspa accepting blocks document the transactions. They do not prove that Kaspa independently verified Ethereum’s consensus.

    The recorded bridge shows an external test asset entering and leaving Kaspa. It is separate from the town’s tKAS purchases: wTestUSD cannot buy crops in the town.

    Free test coins have no monetary value. This unaudited experiment is not a mainnet bridge.

    Path to real capital

    Native backing and external custody are different problems. A real external-asset bridge also needs a defined custodian or proof system, reliable deposit and withdrawal handling, independent security review, and clear responsibility when an oracle fails.

    What these applications establish

    These are experimental, unaudited contracts on Testnet-10. The browser connects directly to a community node. The faucet only sends test coins to your address; it never receives your wallet keys.

    All example roles belong to this tab. Treasury signatures demonstrate a threshold, not independent people approving. The prediction oracle chooses an outcome; it does not verify an outside event. Proof payout verifies a published fixture, not a private computation you created.

    Timed actions use the connected node’s median time. Release and refund can race; the first accepted spend wins. A missing submission response remains uncertain and blocks new spending until matching outputs are observed. Closing the tab does not cancel a transaction.

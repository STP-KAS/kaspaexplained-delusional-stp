Need or questions

Ask in the rooms that already exist.

Kaspa Discord is the help desk. It is not one chat. There are dedicated subtopics: wallets, development, covenants, research, mining, merchants. Browse first. Then ask. Nobody here can recover a seed.

Open Kaspa Discord ↗

If that channel link does not open, join first: discord.gg/kaspa.

How to ask well

Browse to the correct Discord tab. Say what you did, the problem you encountered, which network (mainnet or Testnet-10), which wallet, the error text, the question you have, and anything else that matters. Do not paste a recovery phrase. Do not ask for a price.

See the network without a ticker.

kaspa.stream is an explorer for the many: blocks, transactions, and a live picture of the DAG. You do not need a thesis to open it. You need a transaction ID, an address, or curiosity.

What kaspa.stream is

A block explorer with real-time network insight. Paste an address or a transaction. Watch new blocks land. It is a window onto the ledger, not a trading desk.

Open kaspa.stream ↗

Testnet-10 explorer

Same kind of window, for Testnet-10. Paste a kaspatest: address or a test tx. Mainnet kaspa.stream will not show those coins.

Open tn10.kaspa.stream ↗

What the Graph Inspector is

kgi.kaspad.net draws the blockDAG as it grows. Parallel blocks are the point. A candle chart is not.

# Contributing

Corrections are welcome when they make an explanation clearer, a claim more accurate, or an interaction easier to use.

Project boundaries and relevant references are in `AGENTS.md`. For factual changes, include a primary source, the date of any moving value, and the distinction between protocol support and usable tools or products. Update `CLAIMS.yml` when the claim is tracked there.

Use the checks appropriate to your change in `MAINTENANCE.md`. Install pinned dependencies with `npm ci`. A release requires the full site gate; external link checking is available separately through `bash scripts/check-links.sh`.
